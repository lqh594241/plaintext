03 / THE SMALL PRINT

A few clear answers.
The details that help you get better copy.
Does this use an AI model?
No. This is a local formatting tool for Markdown, including text copied from an AI assistant. It does not send your text to a model or rewrite its meaning.
Is this a full Markdown parser?
No. Common headings, fences, lists, block quotes, emphasis, inline links and pipe tables are supported. Deeply nested lists, complex link syntax, math and arbitrary embedded HTML may need manual editing.
Can I export a table to Excel?
Table mode exports CSV using quoted cells and CRLF row endings. It processes the first standard pipe table with a separator row. Spreadsheet applications can interpret formula-like text; inspect untrusted cells before opening the file.
Can I paste the HTML into a document?
Preview mode exports a basic HTML document with escaped content. It is suitable for opening in a browser or importing into compatible editors, but it is not a DOCX file and does not promise Word-specific layout fidelity.
